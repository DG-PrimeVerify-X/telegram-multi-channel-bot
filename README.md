# Telegram Multi-Channel Bot — Admin GUI v1

Includes:
- Owner-only Admin Management GUI
- Add admin by forwarding a message
- Admin list and admin detail view
- Per-admin permissions
- Remove admin
- SQLite admin_permissions table
- aiogram FSM storage

Next modules: channel management, join requests, auto-DM/content, broadcast, users, stats, logs, rental isolation.
Do not upload `.env`, `venv/`, `data/*.db`, or logs.
